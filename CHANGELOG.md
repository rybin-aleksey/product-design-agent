# Changelog

Версии шаблона агента. Продукт обновляется до нужного тега: `git merge vX.Y.Z` (подробно — в [UPDATING.md](UPDATING.md)).

Формат версии: `MAJOR.MINOR.PATCH`
- **MAJOR** — меняется структура папок или контракты скиллов; в продукте нужны ручные действия.
- **MINOR** — новый скилл, workflow или знание; продукт обновляется без действий.
- **PATCH** — исправления текста и мелкие правки.

В каждой записи раздел «Что сделать в продукте» — если после обновления нужны ручные шаги.

## v1.0.0

Первая версия шаблона: один продукт, много задач.

- Структура `workspace/product/` с контекстом, задачами и общей папкой дизайн-системы `ds/`.
- Скилл `design-system-from-0` — стартовая дизайн-система с нуля.
- Скилл `design-system-scan` — индексирование существующей дизайн-системы из Figma.
- Workflow `design-task` с ветками создания и подключения дизайн-системы.
- Контракт дизайн-системы подхватывается по правилу в `AGENTS.md`; корневые `CLAUDE.md` и `AGENTS.md` скиллы не меняют.
- `UPDATING.md`, `CHANGELOG.md`, `.gitattributes` для обновления продуктов из шаблона.
