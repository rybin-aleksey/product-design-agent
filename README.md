# Product Design Agent

File-based workspace for product design workflows, skills, knowledge, and project artifacts.

## Структура

```text
product-design-agent/
├── .agents/       # Codex и совместимые агенты
├── .claude/       # Claude Code
├── workflows/     # Сценарии работы
├── skills/        # Продуктовые навыки
├── knowledge/     # База знаний
├── workspace/     # Рабочие материалы
├── audit/         # Аудит и журналы
└── README.md
```
