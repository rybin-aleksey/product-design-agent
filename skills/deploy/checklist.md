# Чек-лист: публикация и деплой

## Перед стартом

- [ ] Пользователь явно запустил deploy.
- [ ] Первый запуск или обновление — определено по разделу «Публикация» в `workspace/product/project.md`.
- [ ] Путь выбран: сервис или свой сервер.

## Подготовка

- [ ] `npm run build` проходит, `dist/` свежий.
- [ ] `base: '/'`, `.gitignore` с `node_modules`, `dist`, `.env*`.
- [ ] Секретов в коде нет; `VITE_*` — только несекретные.
- [ ] SPA-fallback настроен (`vercel.json` / `public/_redirects` / nginx `try_files`).

## Путь A

- [ ] Репозиторий содержит актуальный прототип (обновлён через github-handoff).
- [ ] Root Directory указан, если в репозитории весь проект.
- [ ] Сборка на сервисе успешна.
- [ ] Vercel: Deployment Protection не требует входа (проверено в приватном окне).
- [ ] Записана стабильная ссылка (Production Domain), а не URL билда.

## Путь B

- [ ] Вход по SSH-ключу (или пароль — только в окружении команды).
- [ ] Разведка: ОС, порты, nginx, firewall, место — до любых изменений.
- [ ] План показан и подтверждён.
- [ ] Порт свободен, VPN не задет (порты до и после сравнены).
- [ ] Отдельный конфиг nginx, `nginx -t` перед reload; чужие конфиги не тронуты.
- [ ] Заливка — только `dist`, атомарная замена.
- [ ] Firewall: правило добавлено только при активном `ufw`; неактивный не включён; панель провайдера проверена.

## Self-check (перед финалом)

- [ ] Задеплоен свежий билд.
- [ ] **Прямой переход и обновление на внутреннем экране — без 404.**
- [ ] `.env`, `node_modules` не в репозитории и не на сервере.
- [ ] Пароль, токены, ключи не в файлах, `.git/config`, `project.md`, ответах.
- [ ] Живая ссылка открывается и записана в `project.md`.
- [ ] Пользователю напомнено сменить пароль / отозвать токен, если они передавались в чат.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| 404 на внутренних экранах | Нет SPA-fallback | `vercel.json` / `public/_redirects` / `try_files $uri /index.html` |
| `_redirects` не работает на Netlify | Файл в корне проекта, а не в `public/` | Перенести в `public/`, чтобы попал в `dist/` |
| На сервисе старая версия | Репозиторий не обновлён | Обновить через github-handoff, дождаться пересборки |
| Сборка на сервисе падает | Нет Root Directory или другая версия Node | Root Directory = `workspace/product/code`; версия Node в настройках |
| Ссылка Vercel просит логин | Deployment Protection | Выключить Vercel Authentication |
| Vercel отдаёт 403 всем | Частый `curl` включил Security Checkpoint | Ждать 10–30 мин или выключить Attack Challenge Mode; статус — по GitHub |
| Vercel не собирает коммит | Email автора не привязан к GitHub | Коммитить email'ом аккаунта |
| Ссылка перестала обновляться | Скопирован URL билда | Production Domain проекта |
| После деплоя пропал VPN | Порт занят / изменён чужой конфиг / включён ufw | Откатить свой конфиг, вернуть порт; не включать ufw |
| `http://IP:порт` не открывается | Закрыт порт в firewall провайдера | Открыть порт в панели провайдера |
| SSH ждёт пароль и висит | Нет ключа, интерактивный ввод | Добавить SSH-ключ (B1.2) |
