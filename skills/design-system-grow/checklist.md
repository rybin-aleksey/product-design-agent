# Чек-лист: расширение UI-кита

Проходи по гейтам последовательно. Непройденный пункт значит, что следующая фаза не начинается.
`ds/` означает `workspace/product/ds/`.

## Перед стартом

- [ ] Папка задачи определена (`workspace/product/tasks/<TASK-ID>/`).
- [ ] `ds/CONTRACT.md`, `ds/foundation.md`, `ds/components.md` прочитаны целиком.
- [ ] `components.md` не пуст (иначе — `design-system-from-0` или `design-system-scan`).
- [ ] Источник ДС не корпоративный (иначе — локальный паттерн в `ds/patterns.md` по контракту).

## Фаза 1. Каталог и выбор

- [ ] Выписаны имена существующих компонентов и покрытые разделы.
- [ ] Из списка типовых пробелов убрано то, что уже есть.
- [ ] Для каждого компонента сделан чек на дубликаты по имени и назначению.
- [ ] Итоговый набор подтверждён пользователем.

## Фаза 2. Описания

- [ ] Описания собраны в `tasks/<TASK-ID>/analysis/grow-ui-kit-draft.md` по шаблону.
- [ ] У каждого компонента 2–3 варианта, не больше.
- [ ] Отступы только из `space-*`, привязки только к существующим Semantic Variables и TextStyles.
- [ ] Недостающие токены / стили помечены как блокер.
- [ ] **Апрув получен по каждому компоненту.** До этого — ни одного MCP-вызова.

## Фаза 3. Figma

- [ ] Ссылка на тот же файл, вызван `create_session`, загружен скилл `figma-use`.
- [ ] Подготовительное чтение: найдены «Foundation», Variables, TextStyles; всё нужное есть.
- [ ] Секция «UI Kit — extended» создана рядом с «Foundation» (или переиспользована, без дубля).
- [ ] Пакеты по 2–3 компонента, без `throw` в конце мутирующих вызовов.
- [ ] После каждого пакета отдельная проверка: тип узла, `textStyleId`, привязки fills/strokes, отступы.
- [ ] Новых TextStyles не создано.
- [ ] Скриншот секции показан пользователю.

## Фаза 4. Каталог и аудит

- [ ] Новые записи дописаны в `ds/components.md` с фактическими Node ID, существующие не тронуты.
- [ ] Конфликты имён помечены и решены пользователем.
- [ ] Аудит выполнен одним read-only вызовом, отчёт показан построчно.
- [ ] Все расхождения исправлены через `use_figma`, аудит повторён.
- [ ] Финальный отчёт выдан по шаблону.
- [ ] Корневые `CLAUDE.md` и `AGENTS.md`, `ds/foundation.md`, `ds/CONTRACT.md` не изменены.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Лог «applied=N», в файле пусто | `throw` в конце мутирующего вызова откатил транзакцию | Убрать `throw`, отчёт — отдельным read-only вызовом |
| `findOne` вернул `FRAME` | Компонент собран `createFrame()` без `createComponentFromNode` | Пересобрать как `ComponentNode` / `ComponentSet` |
| Пустой `textStyleId` | Стиль не найден из-за пробелов вокруг `/` или шрифт не загружен | Нормализовать имя, `loadFontAsync(style.fontName)` перед применением |
| SOLID без `boundVariables` | Привязка отвалилась на длинном пакете | Пересобрать компонент меньшим пакетом |
| Варианты не видны в Properties | Имена вариантов не в формате `Property=value` | Переименовать до `combineAsVariants` |
| Дубль секции «UI Kit — extended» | Повторный прогон без поиска существующей | Перенести компоненты в первую секцию, лишнюю удалить с согласия пользователя |
