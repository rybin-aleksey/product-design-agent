# Чек-лист: индексирование существующей ДС

Проходи по гейтам последовательно. Непройденный пункт значит, что следующая фаза не начинается.
`ds/` означает `workspace/product/ds/`. Все файлы ДС создаются только там.

## Перед стартом

- [ ] Папка задачи определена (`workspace/product/tasks/<TASK-ID>/`) — для рабочих заметок в `analysis/`.
- [ ] ДС в Figma действительно существует (иначе — скилл `design-system-from-0`).
- [ ] Файлов в `ds/` ещё нет, либо это повторное сканирование и пользователь разрешил перезапись.
- [ ] Контекст продукта из `context/` прочитан.

## Фаза 1. Контекст

- [ ] Четыре вопроса заданы одним блоком.
- [ ] Ссылка ведёт именно на страницу Components (есть `node-id` страницы), а не на корень файла.
- [ ] Для Community-библиотеки получена ссылка на собственную копию.
- [ ] Указано, где лежит фундамент: в том же файле или в отдельном.
- [ ] `ds/source.md` сохранён.

## Фаза 2. Foundation

- [ ] Вызван `create_session`, загружен скилл `figma-use`.
- [ ] Variables прочитаны одним плоским read-only вызовом.
- [ ] Токены разложены по слоям; привязки Semantic → Primitive отражены как есть.
- [ ] Плоская коллекция или отсутствие Variables помечены в замечаниях.
- [ ] Режимы коллекций перечислены.
- [ ] При локали `ru` / `ru+en` указан статус кириллицы в шрифте.
- [ ] **Файл показан пользователю, неясные токены уточнены.**

## Фаза 3. Components

- [ ] Прочитан только верхний уровень страницы + один уровень группировщиков.
- [ ] Ни одного захода в инстансы и внутрь компонентов.
- [ ] Для 300+ компонентов сканирование разбито на прогоны по 50–80.
- [ ] У каждого компонента есть Node ID.
- [ ] Матрицы вариантов записаны строкой `key: val1 | val2`.
- [ ] Назначения на русском; пустые `description` помечены.
- [ ] Self-check: доля пустых назначений, пустые `componentPropertyDefinitions`, подозрительные имена, старые версии, дубликаты.
- [ ] `ds/components.md` сохранён.

## Фаза 4. Показ

- [ ] Сводка с числами и замечаниями показана пользователю.

## Фаза 5. Контракт

- [ ] `ds/CONTRACT.md` создан, источник, ссылка на Figma и дата заполнены.
- [ ] Раздел «Что делать, если нужного нет» соответствует источнику.
- [ ] Корневые `CLAUDE.md` и `AGENTS.md` не изменены.
- [ ] В Figma ничего не изменено.
- [ ] Финальный отчёт выдан по шаблону.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Таймаут или обрезанный ответ MCP | Ссылка на корень файла, рекурсивный обход | Переспросить ссылку на страницу Components, читать только `page.children` |
| Пустой каталог | Компоненты лежат глубже одного уровня группировки | Попросить ссылку на конкретную секцию или автора ДС — поднять компоненты |
| Variables пустые | Фундамент в отдельном файле или ДС на Styles | Взять ссылку на файл фундамента или прочитать Paint/Text Styles |
| В Semantic сырые значения вместо alias | Привязки в ДС не сделаны | Пометить «не сделаны» в замечаниях, в Figma не исправлять |
| Ключи свойств вида `Label#123:0` | Figma добавляет суффикс к не-вариантным свойствам | Отрезать суффикс `#…` при записи |
