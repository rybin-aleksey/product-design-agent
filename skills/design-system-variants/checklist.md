# Чек-лист: расширение матрицы вариантов и состояний

Проходи по гейтам последовательно. Непройденный пункт значит, что следующая фаза не начинается.
`ds/` означает `workspace/product/ds/`.

## Перед стартом

- [ ] Папка задачи определена (`workspace/product/tasks/<TASK-ID>/`).
- [ ] `ds/CONTRACT.md`, `ds/foundation.md`, `ds/components.md` прочитаны целиком.
- [ ] Источник ДС не корпоративный.
- [ ] Режим определён: single (есть имя) или bulk.
- [ ] Bulk: список неполных компонентов показан, по каждому получено «да» или «нет».

## Фаза 1. Read

- [ ] Запись компонента найдена в `components.md` (иначе — `design-system-grow`).
- [ ] Компонент прочитан read-only: тип, оси, ячейки, структура дефолтной ячейки.
- [ ] Расхождения md ↔ Figma показаны и решены пользователем.
- [ ] Фактические имена осей зафиксированы; переименование — только с согласия.

## Фаза 2. Brief

- [ ] Текущая матрица показана одной строкой.
- [ ] Три вопроса заданы одним блоком; ответы конкретные.
- [ ] Если все три пустые — прогон закрыт.

## Фаза 3. md

- [ ] Новая матрица и её размер посчитаны; при 25+ ячеек предложено дробление.
- [ ] Исключённые ячейки (если есть) перечислены явно.
- [ ] Недостающие Semantic предложены как alias к Primitive; **апрув получен**.
- [ ] Описание ячеек, состояний и размеров сохранено в `analysis/component-variants-<name>.md`; **апрув получен**.
- [ ] До этого момента — ни одного мутирующего MCP-вызова.

## Фаза 4. Canvas

- [ ] `create_session` вызван, скилл `figma-use` загружен.
- [ ] Новые Semantic созданы в Figma как `VARIABLE_ALIAS` (во всех режимах коллекции).
- [ ] Одиночный компонент промоутнут в Set, инстансы не потеряны, новый Node ID записан.
- [ ] Новые ячейки — клоны дефолтной, имена `Property=value, …`; существующие не пересозданы.
- [ ] Один мутирующий вызов на компонент (или на половину матрицы), без `throw` в конце.
- [ ] Проверка: оси в `componentPropertyDefinitions`, число ячеек, привязки fills/strokes, `textStyleId`, точечная ячейка.
- [ ] Скриншот Set'а показан пользователю.

## Фаза 5–6. Каталог и отчёт

- [ ] Строка вариантов в `components.md` обновлена, пометка о расширении добавлена.
- [ ] Новые токены дописаны в `foundation.md` без дублей.
- [ ] Отчёт выдан по шаблону (single или bulk).
- [ ] Корневые `CLAUDE.md` и `AGENTS.md` не изменены.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Ячейки есть, а осей в Properties нет | Имена через слэш вместо `Property=value` | Переименовать ячейки в `Property=value, …` |
| Лог «applied=N», в файле пусто | `throw` в конце мутирующего вызова | Убрать `throw`, проверка — отдельным вызовом |
| Fill не привязан после `setBoundVariable("fills", …)` | Для цвета нужен `setBoundVariableForPaint` | Пересобрать paint через `setBoundVariableForPaint` |
| Инстансы на экранах «отвалились» | Существующие ячейки пересозданы или Set собран заново | Не пересоздавать существующие ячейки, промоут — через `combineAsVariants` исходного компонента |
| Hover не перекрашивается при смене акцента | Semantic создан с прибитым значением | Пересоздать токен как `VARIABLE_ALIAS` |
| Часть ячеек без Auto Layout / съехали размеры | Ячейка создана с нуля, а не клоном | Пересоздать новую ячейку клоном дефолтной |
