# Чек-лист: передача на GitHub

## Перед стартом

- [ ] Пользователь явно запустил handoff.
- [ ] `git --version` есть.
- [ ] Первый запуск или повторный — определено по `workspace/product/project.md`.
- [ ] Способ авторизации определён: менеджер учётных данных / `gh` / токен.

## Фаза 0–1

- [ ] Шаги «пустой репозиторий» (+ токен, если нужен) выведены; ссылка получена.
- [ ] Токен (если есть) — classic, scope `repo`, со сроком; не сохранён нигде.
- [ ] Выбрана заливаемая часть; для «всего проекта» пользователь предупреждён про контекст и исследования.
- [ ] `.gitignore` создан или дополнен.
- [ ] Проверка на секреты пройдена.
- [ ] Состав и объём показаны, **подтверждение получено**.

## Self-check (перед финалом)

- [ ] Пуш прошёл одной операцией, одним коммитом — не пофайлово.
- [ ] `node_modules`, `dist`, `build`, `storybook-static`, `.env` не в репозитории.
- [ ] Токен не попал в `.git/config`, коммиты, `project.md`, README или ответы.
- [ ] `origin` и `template` продукта не изменены; для всего проекта — remote `handoff`.
- [ ] README разработчика на месте; корневой `README.md` шаблона не тронут.
- [ ] Раздел «Репозиторий разработки» в `project.md` записан.
- [ ] Ссылка открывается, ветка `main` (или согласованная ветка при повторном запуске).
- [ ] Пользователю напомнено отозвать токен (если использовался).

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Заливка идёт десятки минут | Пофайловая загрузка через API | Только `git commit` + один `git push` |
| `rejected (fetch first)` | Репозиторий создан с README / license | `git pull --rebase`, затем `push`, без `--force` |
| 403 на приватный репозиторий | У токена нет scope `repo` или вошли не тем аккаунтом | Новый токен с `repo` / сменить учётную запись в менеджере |
| В репозитории `node_modules` | `.gitignore` создан после `git add` | `.gitignore` до `add`; иначе `git rm -r --cached node_modules` и новый коммит |
| Токен в `.git/config` | Remote добавлен как `https://<TOKEN>@github.com/...` | Remote без токена, авторизация через заголовок в одной команде; токен отозвать |
| Пуш ушёл в репозиторий продукта | Использован `origin` вместо отдельного remote | Для всего проекта — remote `handoff`; для части — отдельная рабочая копия |
