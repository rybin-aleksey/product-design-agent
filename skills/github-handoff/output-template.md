# Шаблоны

## Шаги для пользователя (фаза 0)

```text
Чтобы передать проект разработке, нужен пустой репозиторий на GitHub.

Шаг 1. Создай пустой репозиторий
1. Открой github.com и войди в аккаунт.
2. Справа вверху «+» → New repository.
3. Repository name — латиницей, например <product>-design-system.
4. Выбери Private.
5. Галочки README, .gitignore, license НЕ ставь — репозиторий должен быть пустым.
6. Create repository → скопируй адрес страницы (https://github.com/<аккаунт>/<имя>) и пришли мне.
```

Если нет менеджера учётных данных и `gh`:

```text
Шаг 2. Создай токен для заливки
1. Аватар справа вверху → Settings → Developer settings → Personal access tokens → Tokens (classic).
2. Generate new token → Generate new token (classic).
3. Note — любое название, например «handoff».
4. Expiration — 30 дней (бессрочный не нужен).
5. Отметь только scope «repo» — этого достаточно для приватного репозитория.
6. Generate token → скопируй токен сразу: второй раз GitHub его не покажет.
7. Пришли токен мне. Я использую его только для одной заливки и никуда не сохраняю.
   После передачи токен лучше удалить там же, в Tokens (classic).
```

Если есть менеджер учётных данных:

```text
Токен не нужен: при заливке откроется окно входа в GitHub — просто войди в свой аккаунт.
```

```text
Подтверждение: заливаю <N> файлов (<X> МБ) из <часть> в <ссылка>, ветка main. node_modules, dist, .env исключены. Ок?
```

## README для разработчика

~~~markdown
# <Продукт> — дизайн-система и компонентная база

React-база компонентов и каталог Storybook, собранные по дизайн-системе продукта.

## Состав
- `src/tokens/` — токены: Primitive и Semantic (источник — Figma Variables)
- `src/components/` — компоненты: <список>
- `.storybook/` — каталог: Foundation, компоненты со всеми вариантами и состояниями, песочницы

## Запуск
```bash
npm install
npm run dev          # приложение / превью
npm run storybook    # каталог на http://localhost:6006
```

## Источник правды
- Макеты и UI-кит: <ссылка на Figma-файл>
- Токены и варианты компонентов соответствуют Figma; изменения в ДС вносятся сначала в Figma.

## Правила
- Стили — только через токены из `src/tokens/`, без прибитых значений.
- Новый компонент — сначала в ДС, затем в базе и каталоге.
~~~
