# Чек-лист: сборка экрана из базы

`code/` — `workspace/product/code/`.

## Перед стартом

- [ ] Пользователь явно запустил screens и прислал ссылку на фрейм (с `node-id`).
- [ ] React-база есть и поднимается.
- [ ] `ds/CONTRACT.md`, `ds/components.md`, `src/components/index.ts` прочитаны.
- [ ] Каркас: роутер (новая зависимость — только с согласия), `registry.ts`, индекс «/».

## Чтение и декомпозиция

- [ ] `create_session`, скилл `figma-design-to-code` загружен до `get_design_context`.
- [ ] `get_metadata` → `get_design_context` по секциям → `get_screenshot`.
- [ ] Composition map экрана (если есть) учтена.
- [ ] Карта блоков: база / локальный блок / компонент ДС, которого нет в базе (решение пользователя).

## Self-check (перед финалом)

- [ ] Каждый блок — из базы или локальный блок на базе; компонентов «мимо базы» нет, база не изменена.
- [ ] Нет прибитых hex / px там, где есть токен.
- [ ] Раскладка из Auto Layout (flex / grid), без абсолютных координат; держится на разной ширине и при длинном контенте.
- [ ] Контент — статикой из макета; **нет логики, обработчиков, состояния, слоя данных, моков, рабочих форм.**
- [ ] Экран в реестре, роут не задублирован, открывается; остальные экраны не сломаны.
- [ ] Индекс «/» строится из реестра; новый экран — кликабельная плитка (название + описание + роут); на экране есть «← Все экраны».
- [ ] Заметка `src/screens/<name>/<name>.md` записана.
- [ ] `npm run dev` и сборка / типы — без ошибок; консоль чистая.
- [ ] Ничего не закоммичено без указания.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Прочиталась не та страница | Ссылка на корень файла | Ссылка на фрейм через Copy link to selection |
| Переполнение контекста | `get_design_context` на весь большой фрейм | Сначала `get_metadata`, затем контекст по секциям |
| Экран ломается при сужении окна | Абсолютные координаты, фиксированные ширины, нет `min-width: 0` | Перенос Auto Layout в flex / grid по таблице |
| Чужой компонент «натянут» на блок | Нет точного совпадения в базе | Локальный блок в `parts/` |
| Появились `useState`, моки, обработчики | Агент начал оживлять | Откатить: это следующий шаг |
| Экран есть, но его не найти | Не добавлен в реестр / индекс захардкожен | Реестр — единая точка, индекс строится из него |
| Два одинаковых роута | Повторный запуск без сверки с реестром | Обновлять существующую запись |
