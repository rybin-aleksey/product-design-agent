## Self-check (перед финалом)

- [ ] Навигация: переходы по меню / кнопкам / ссылкам, «назад», активный пункт, 404.
- [ ] Экраны читают данные из единого слоя `src/data/`, действия его меняют; вшитой статики в оживлённых экранах не осталось.
- [ ] Начальные данные повторяют макет; расширение реалистично и помечено как демо.
- [ ] Формы: валидация (обязательные, форматы, границы), ошибка у поля, loading и защита от двойной отправки, результат на отправку.
- [ ] Продуктовая логика — по ответам пользователя, записана в «Поведение»; невыясненное помечено, а не выдумано.
- [ ] Состояния: загрузка / успех / ошибка / пусто для каждого действия и списка в скоупе.
- [ ] Edge cases: границы, доменные края, «ничего не найдено», переполнение, подтверждение деструктивных действий; дополнительные — по выбору пользователя.
- [ ] Переключатель сценариев работает, сценарии перечислены в заметках.
- [ ] Всё на компонентах базы и семантических токенах; прибитых значений нет.
- [ ] Доступность: фокус, `aria-live`, связь ошибок с полями, `prefers-reduced-motion`.
- [ ] Новые зависимости — только согласованные.
- [ ] Нет бэкенда, реальных запросов, деплоя, метрик.
- [ ] `npm run dev` и сборка — без ошибок; консоль чистая.
- [ ] Ничего не закоммичено без указания.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Действие «успешно», а список не изменился | Экран остался на статике | Перевести экран на чтение из хранилища |
| Агент добавил fetch / ключи API | Ушёл в бэкенд | Откатить, только мок-API в `src/data/api.ts` |
| Состояние загрузки не видно | Мок отвечает мгновенно | Задержка 300–800 мс в мок-API |
| Ошибку невозможно показать | Нет управляемой ошибки | Сценарий `?scenario=error` |
| После повторного запуска сломались старые экраны | Переписан общий слой / навигация | Наращивать: дописывать, не переписывать |
| Ошибка формы стёрла введённое | Сброс состояния формы при ошибке | Сохранять значения, показывать ошибку |
| Выдуманная бизнес-логика | Агент додумал вместо вопроса | Спросить пользователя, пометить невыясненное |
| Цвета ошибок прибиты | Нет токена под состояние | Использовать Semantic; нет — предложить добавить в Foundation |
