# Чек-лист: аудит экранов

Проходи по гейтам последовательно.
`ds/` — `workspace/product/ds/`, `tasks/` — `workspace/product/tasks/`.

## Перед стартом

- [ ] Режим определён: audit only (по умолчанию) или `--fix`; скоуп — все экраны или один.
- [ ] `ds/CONTRACT.md`, `ds/foundation.md`, `ds/components.md` прочитаны.
- [ ] Composition maps всех задач и последний отчёт аудита прочитаны.

## Фаза 0. Входы

- [ ] Секция «Screens» найдена (иначе — прогон закрыт с отсылкой к final-screens).
- [ ] Экраны сопоставлены с composition maps; расхождения записаны в раздел 0.
- [ ] Компоненты прочитаны по Node ID из каталога; Variables, EffectStyles, TextStyles получены.

## Фаза 1. Проверки

- [ ] Один read-only вызов на экран, возвращаются только находки.
- [ ] Проверка 1: `detachedInfo` + эвристика (2+ признака), уверенность указана.
- [ ] Проверка 2: fills / strokes / effects / тексты; совпадение с Semantic по роли; источник — экран или мастер.
- [ ] Проверка 3: подозрения с причиной, разные смыслы не помечены.
- [ ] Проверка 4: `unused`, `stale`, `unrecorded`; вложенность в мастерах учтена.
- [ ] Проверка 5: `unused-variants` (с учётом интерактивных состояний), `custom-detached`, `matrix-mismatch`.
- [ ] Проверка 6: тип блока, матрица, контекст экрана; осознанные пропуски исключены.
- [ ] Ни одного мутирующего вызова.

## Фаза 2. Отчёт

- [ ] Отчёт по шаблону, у каждой находки — действие и «автофикс / кому передать».
- [ ] Решение по каждой находке: чинить / пропустить / не решать сейчас.

## Фаза 3. Автофиксы

- [ ] Только в `--fix` и только на «чинить».
- [ ] Без `throw` в конце мутирующих вызовов; проверка после каждого раздела.
- [ ] Замена на instance — с переносом текстов и sizing; удалён только узел из находки.
- [ ] Фиксы в мастерах — только для своей / Community ДС и с отдельным апрувом.

## Фаза 4–5. Запись и финал

- [ ] Отчёт сохранён в `tasks/<TASK-ID>/analysis/screens-audit-<дата>.md` с решениями и «было / стало».
- [ ] `ds/components.md` изменён только по решениям пользователя.
- [ ] Осознанные пропуски записаны в composition maps.
- [ ] Задачи для final-screens / design-system-variants сформулированы брифом.
- [ ] Финальный отчёт выдан.
- [ ] Корневые `CLAUDE.md` и `AGENTS.md` не изменены.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Сотни находок «прибитый цвет» внутри инстансов | Считаются слои мастера | Проверить мастер отдельно, в отчёт — источник, а не каждое вхождение |
| Таймаут или обрезанный ответ | Возврат дерева экрана целиком | Возвращать только находки, один экран на вызов |
| hover / focus помечены как «забыли» | Интерактивные состояния не видны на статичном макете | Помечать как норму |
| Тот же вопрос, что в прошлом аудите | Не прочитаны прошлые решения | Читать последний отчёт и разделы «осознанно пропущены» |
| После замены пропал текст кнопки | Тексты не перенесены в instance | Переносить через TEXT-свойства, спорное — спрашивать |
| Badge помечен unused | Используется только внутри другого компонента | Учитывать вложенность в мастерах |
