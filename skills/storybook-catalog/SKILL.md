# Каталог компонентов в Storybook (storybook)

## Назначение

Собрать на React-базе продукта аккуратный каталог: каждый компонент в изоляции со всеми вариантами и состояниями, живые переходы между состояниями, песочницы с компонентами в связке, все токены. Каталог — зеркало ДС, инструмент сверки с Figma и форма передачи разработке.
контекст → установка → Foundation → stories → переходы → песочницы → (опц.) сложные кейсы → запуск и проверка.

## Когда использовать

- Запускается из ветки «Каталог компонентов в Storybook» в [workflows/design-task](../../workflows/design-task/README.md) **только по явной команде пользователя** (`storybook`, «собери каталог в Storybook»). Это задача с кодом: прямой запрос пользователя — условие из `AGENTS.md`.
- Собрана React-база: `workspace/product/code/` с `src/components/` (имена — из `ds/components.md`) и `src/tokens/` (Primitive + Semantic), проект поднимается.
- Повторный запуск: в базе появились компоненты или варианты — каталог дополняется (фаза 8).

**Не использовать**, если React-базы нет: сначала её нужно собрать (директива react_base; в шаблоне для неё пока нет скилла). Каталог не рисует компоненты заново.

## Роль

Фронтенд-разработчик дизайн-систем: собирает Storybook-каталоги, пишет stories в CSF3, держит стили на токенах. Делает каталог аккуратным, а не «голым рендером». Дизайнер направляет и смотрит каталог, код правит агент.

## Входные данные

- `ds/CONTRACT.md`, `ds/components.md` (состав, матрицы), `ds/foundation.md` (все токены).
- Контекст продукта из `workspace/product/context/` — для осмысленных `args` и демо-контента.
- Кодовая база `workspace/product/code/`: `src/components/index.ts`, `src/tokens/`.
- Node.js 18+ и npm.

## Фазы

| Фаза | Что делаем | Результат | Гейт |
|---|---|---|---|
| 0. Контекст | `components.md` × `src/components/index.ts`, токены | Состав каталога | Расхождения показаны пользователю |
| 1. Установка | `storybook init --yes` (если нет `.storybook/`), чистка примеров, токены в preview | Рабочий Storybook | Стартует |
| 2. Foundation | Primitive, Semantic, типографика из `src/tokens/` | Раздел `Foundation` | Значения не захардкожены |
| 3. Stories | CSF3 + autodocs на каждый компонент | `<Name>.stories.tsx` | У каждого `autodocs`, `argTypes`, `AllVariants` |
| 4. Переходы | `transition` на интерактивных состояниях | Живые hover / active / focus | На токенах |
| 5. Песочницы | Компоненты в связке по блокам | `Sandboxes/<Блок>` | Из реальных компонентов |
| 6. Сложные кейсы | Предложить, не делать молча | Доп. stories или пропуск | Ответ пользователя |
| 7. Запуск | `storybook --ci`, проверка, показ | Адрес и состав | Self-check пройден |
| 8. Обновление | Только дописать недостающее | Дополненный каталог | — |

Подробности, команды и шаблоны — в [methodology.md](methodology.md).
Гейты и self-check — в [checklist.md](checklist.md).
Канонический шаблон story и финальный отчёт — в [output-template.md](output-template.md).

## Жёсткие правила

1. **Каталог — из настоящих компонентов базы** (`import` из `src/components/`), не перерисовка.
2. **Состав и имена — из `ds/`** и базы; сверх базы ничего не выдумываем.
3. **Единый формат stories** для всех компонентов: `tags: ['autodocs']`, `argTypes` на каждый проп, именованные stories по матрице, `AllVariants`, JSDoc.
4. **Только токены в стилях**, включая правки базы (переходы) — по `ds/CONTRACT.md`.
5. **Init — один раз.** Есть `.storybook/` — init не запускаем.
6. **Неинтерактивные команды:** `init --yes`, запуск `--ci` в фоне.
7. **Сложные кейсы и доп. анимации — по желанию пользователя**, не молча.
8. **Демо-контент — из контекста продукта**, не lorem и не выдуманные факты о продукте.
9. **Ничего не коммитим** без прямого указания пользователя.

## Где сохранять

```text
product-design-agent/
└── workspace/product/code/                # React-база продукта
    ├── .storybook/                        # main.ts, preview.ts(x)
    ├── src/
    │   ├── tokens/                        # источник значений для Foundation
    │   ├── components/<Name>/<Name>.stories.tsx
    │   ├── foundation/*.stories.tsx|mdx   # раздел Foundation
    │   └── sandboxes/*.stories.tsx        # песочницы по блокам
    └── package.json                       # скрипты storybook / build-storybook
```

Если React-база лежит в другом месте — используй её фактический путь и сообщи его пользователю. Корневые `CLAUDE.md` и `AGENTS.md` не меняются.
