# Чек-лист: дашборд юзер-тестов

## Перед стартом

- [ ] Пользователь явно запустил dashboard.
- [ ] Бандл в `workspace/product/dashboard/`; README, примеры конфигов, `server/` и `track.js` прочитаны.
- [ ] Трекер не собирает ввод и персональные данные.
- [ ] Прототип опубликован; путь (http / https) определён по `project.md`.
- [ ] Доступ к серверу по SSH-ключу; разведка read-only сделана; Node 18+.

## План теста

- [ ] Сценарии собраны из реестра, роутера, заметок «Поведение», `task.md` / PRD — без выдуманных экранов.
- [ ] Гипотезы — из материалов проекта, с `flow`, `measure`, `target` (`step` для dropoff); источники указаны.
- [ ] Пороги предложены с обоснованием; **сценарии и пороги утверждены пользователем**.
- [ ] `ut-plan.md` и `hypotheses.json` сохранены в `artifacts/validate/` задачи.

## Self-check (перед финалом)

- [ ] Сбор и туннель работают как systemd-службы (`is-active`), переживают перезапуск.
- [ ] `<АДРЕС СБОРА>/health` отвечает **снаружи**.
- [ ] Путь 2: прототип и сбор по https, туннель с постоянным адресом — mixed content нет.
- [ ] Путь 1: порт открыт только при активном `ufw`; VPN не задет; неактивный `ufw` не включён.
- [ ] Трекер на всех экранах; `data-endpoint` = адрес сбора, не `localhost`.
- [ ] `data-track` на ключевых кнопках, ошибках и пустых состояниях.
- [ ] `config.js`: верные `endpoint`, `prototypeUrl` (реальный стартовый экран), `screens`, `flows`; не в git.
- [ ] Гипотезы на сервере, видны в дашборде.
- [ ] Свой проход по ссылке U-теста виден в дашборде (сессии, клики).
- [ ] Живой URL не опрашивался частыми `curl`.
- [ ] Пароль, ngrok-токен, `DASH_KEY` — не в файлах проекта, `.git`, `project.md`, ответах.
- [ ] Раздел «Юзер-тесты» в `project.md` записан.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| События не доходят, в консоли mixed content | Прототип https, сбор http | Путь 2: ngrok с постоянным адресом |
| Тест рвётся после перезапуска | ngrok без `--url` / процесс в терминале | Служба systemd с `--url=https://<домен>` |
| С телефонов события не идут | `data-endpoint` = `localhost` | Публичный адрес сбора |
| `/health` снаружи не отвечает (путь 1) | Порт закрыт в панели провайдера / занят | Открыть порт, выбрать свободный |
| Сценарии смешались | Общий стартовый экран без метки | Раздавать `prototypeUrl?ut_task=<id>` |
| Респонденты попадают на список экранов | `prototypeUrl` = «/» дев-индекса | Стартовый экран сценария |
| Сайт на Vercel отдаёт 403 всем | Частый `curl` включил Security Checkpoint | Ждать 10–30 мин или выключить Attack Challenge Mode; статус — по GitHub |
| Vercel не собирает коммит | Email автора не привязан к GitHub | Коммитить email'ом аккаунта |
| Гипотеза «недостаточно данных» | Нет `flow` / `measure` / `target` или мало сессий | Дополнить поля; больше респондентов |
| Дашборд «не подключён» | Нет `config.js` или пустой `endpoint` | Сгенерировать `config.js` |
| Регистрация в ngrok через GitHub не проходит | GitHub привязан к mail.ru и подобным | Регистрация через Google |
